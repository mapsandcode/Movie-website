# 🎬 Film Sitesi

Netflix tarzında, HTML, CSS ve JavaScript ile geliştirilmiş bir film/dizi keşif arayüzü. Öne çıkan içerik alanı, kategori bazlı kaydırılabilir listeler ve karanlık/aydınlık mod desteği sunar.

## ✨ Özellikler

- **Öne Çıkan İçerik (Hero) Alanı** — Büyük görsel, açıklama ve "Oynat" / "Daha Fazla Bilgi" butonları
- **Kaydırılabilir Film/Dizi Listeleri** — Ok tuşlarıyla yatay kaydırma (Popüler, Yeni Çıkanlar vb.)
- **Hover Efektleri** — Film posterinin üzerine gelince başlık ve aksiyon butonları (oynat, beğen, beğenme, listeye ekle) belirir
- **Karanlık / Aydınlık Mod** — Navbar üzerindeki toggle ile tüm sayfada tema değişimi
- **Kategori Filtresi** — Aksiyon, Animasyon, Dram, Komedi, Bilim Kurgu gibi türlere göre seçim
- **Responsive Tasarım** — Mobil ve küçük ekranlarda uyumlu görünüm
- **Sabit (Sticky) Navbar ve Sidebar** — Sayfa kaydırılırken üstte/solda sabit kalan menüler

## 🛠️ Kullanılan Teknolojiler

- **HTML5** — Sayfa yapısı
- **CSS3** — Stil, animasyon ve responsive tasarım
- **JavaScript (Vanilla)** — Kaydırma mantığı ve tema değiştirme
- **[Bootstrap Icons](https://icons.getbootstrap.com/)** — İkon seti (CDN üzerinden)
- **Google Fonts (Electrolize)** — Yazı tipi

## 📁 Proje Yapısı

```
film-sitesi/
├── index.html          # Ana sayfa
├── style.css            # Tüm stil dosyası
├── script.js             # Kaydırma ve karanlık mod fonksiyonları
└── img/
    ├── profile.jpg
    ├── thedrama-title.png
    ├── thedrama-kapak.jpg
    ├── Filmler/          # Film posterleri
    └── Diziler/          # Dizi posterleri
```

## 🚀 Kurulum ve Çalıştırma

1. Bu depoyu bilgisayarınıza indirin veya klonlayın.
2. `img/` klasörünün `index.html` ile aynı dizinde olduğundan emin olun.
3. `index.html` dosyasını bir tarayıcıda açmanız yeterli — herhangi bir build veya kurulum adımı gerekmez.
4. Projenin canlı haline buradan ulaşabilirsiniz.
   https://fc-moviewebsite.netlify.app

## 🎯 Kullanım

- Kategori filtresiyle hangi türden dizi ve filmlerin listelenebileceğine bakabilirsiniz.
- Sağdaki ok ikonuna tıklayarak film/dizi listelerini yatay olarak kaydırabilirsiniz.
- Sağ üstteki toggle düğmesiyle karanlık/aydınlık mod arasında geçiş yapabilirsiniz.
- Film kartlarının üzerine gelerek başlık ve etkileşim butonlarını (oynat, beğen, listeye ekle vb.) görebilirsiniz.
